# Rückerstattungsrichtlinie

**Zuletzt aktualisiert:** 2. August 2026

Diese Seite fasst zusammen, wie die kostenlose Testphase, die Kündigung und
die Rückerstattungen des Premium-Plans von Purgito funktionieren.

## Kostenlose Testphase (Trial)

Für den Monatsplan gibt es eine kostenlose 7-tägige Testphase. Die Testphase
gilt einmalig pro Kunde (gleicher Käufer oder gleiche Zahlungsmethode),
selbst wenn sie auf einem anderen Server aktiviert wird.

## Kündigung

Das Abonnement wird über das Kundenportal von Polar gekündigt, dessen
Zugang per E-Mail (von Polar, nicht von Purgito) beim Abschluss des
Abonnements zugesandt wird. Eine Kündigung über das Dashboard von Purgito
ist nicht möglich.

## Rückerstattungen

Purgito bietet keine Rückerstattungen für bereits begonnene oder bezahlte
Zeiträume an, egal ob monatlich oder jährlich.

Vor der Zahlung hat jeder Server Zugang zu einer kostenlosen 7-tägigen
Testphase im Monatsplan, die speziell dafür gedacht ist, zu entscheiden,
ob sich Premium lohnt, bevor man sich auf eine Zahlung festlegt. Deshalb
werden nach Beginn des bezahlten Zeitraums keine teilweisen oder
vollständigen Rückerstattungen vorgenommen — weder für die verbleibende
Zeit, noch für die Nutzung des Dienstes, noch für eine spätere
Entscheidung, ihn nicht mehr zu nutzen.

Das Kündigen des Abonnements ist etwas anderes als eine Rückerstattung
anzufordern: Die Kündigung stoppt nur die automatische Verlängerung des
nächsten Zeitraums. Der bereits bezahlte Premium-Zugang bleibt normal bis
zum Ende dieses Zeitraums aktiv — er wird nicht vorzeitig unterbrochen,
und für den Rest dieses Zeitraums wird auch kein Geld zurückerstattet,
wenn du vor dessen Ende kündigst.

Da die Zahlungen von Polar.sh als Merchant of Record abgewickelt werden,
wird jede Zahlungsstreitigkeit (Rückbuchung/Chargeback) direkt zwischen
der zahlenden Person und Polar geregelt, nach den eigenen Bedingungen von
Polar — dies kann dazu führen, dass der Premium-Zugang während der
laufenden Streitigkeit ausgesetzt wird (siehe "Widerruf").

## Widerruf

Der Entwickler von Purgito oder Polar.sh können den Premium-Zugang bei
Betrug, Rückbuchung (Chargeback) oder ungelöstem Zahlungsfehler
widerrufen.

## Was mit deinen Inhalten passiert, wenn der Server Premium verliert

Wenn ein Server Premium nicht mehr hat (durch Kündigung, Widerruf oder das
Ende des bezahlten Zeitraums), werden die bereits gespeicherten Inhalte
(Nachrichten-Corpus, GIFs, Embed-Vorlagen usw.) **nicht gelöscht**. Sie
können lediglich nicht mehr über die Grenzen des kostenlosen Plans hinaus
weiterwachsen: Wenn bereits mehr Inhalte gespeichert waren, als der
kostenlose Plan erlaubt, bleibt dieser Überschuss unverändert erhalten,
bis er durch die normale Nutzung des Bots auf natürliche Weise auf das
kostenlose Limit zuläuft (zum Beispiel verwirft das System die ältesten
Inhalte, sobald neue gespeichert werden, in den Kategorien, die schon so
funktionieren).

## Zuordnung von Premium

Das auf einem Server aktivierte Premium gehört zu diesem Server
(identifiziert durch seine Discord-guild_id), nicht zu der Person oder dem
Konto, das die Zahlung geleistet hat.

In der Praxis bedeutet das:

- Wenn die zahlende Person den Server verlässt, entfernt wird oder die
  Eigentümerschaft des Servers an jemand anderen überträgt, bleibt Premium
  unverändert aktiv — der Server verliert seine Vorteile nicht.
- Die Verwaltung des Abonnements (Kündigen, Plan wechseln, Belege
  einsehen) kann nur von der Person vorgenommen werden, die Zugang zum
  Kundenportal von Polar hat, das mit diesem Kauf verknüpft ist — normalerweise
  die Person, die ursprünglich bezahlt hat. Verliert diese Person den
  Zugang zu ihrer E-Mail oder ihrem Polar-Konto, kann niemand sonst auf
  dem Server das Abonnement direkt verwalten; in diesem Fall muss der
  Entwickler kontaktiert werden, um das im Einzelfall zu klären.
