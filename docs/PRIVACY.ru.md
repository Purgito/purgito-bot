# Политика конфиденциальности (Privacy Policy)

**Последнее обновление:** 16 августа 2026 г.

Эта Политика описывает, как **Purgito** собирает, использует, хранит и защищает информацию, необходимую для предоставления своих функций.

Purgito — публичный бот Discord, используемый на множестве серверов. Данные, которые мы собираем, и то, как мы их обрабатываем, одинаковы для всех серверов, на которых присутствует бот.

---

# 1. Собираемая информация

Для корректной работы бот может хранить следующую информацию:

## Информация Discord

- ID пользователей.
- ID серверов.
- ID каналов.

Эти идентификаторы используются исключительно для внутренней работы бота.

---

## Содержимое сообщений

Когда функции обучения включены, бот сохраняет содержимое текстовых сообщений, отправленных в разрешённых каналах.

Эти сообщения могут использоваться для:

- Обучения локальных цепей Маркова.
- Генерации автоматических ответов в чате.
- Имитации стиля письма пользователей.
- Использования как ограниченного словарного образца при генерации мемов (локально с помощью Маркова или через опциональную интеграцию с Groq, если она настроена).

Каналы, помеченные в Discord как **NSFW**, всегда исключены из этого обучения: Purgito никогда не сохраняет сообщения из NSFW-канала — без исключений и без возможности вручную включить его для корпуса. Если канал, уже включённый в корпус, позже помечается как NSFW, уже сохранённая история этого канала немедленно удаляется.

---

## Медиафайлы

Бот может хранить:

- URL изображений.
- URL GIF-файлов.
- Медиафайлы, необходимые для функций галереи GIF и коллекции мемов.

При необходимости эти файлы могут храниться на постоянной основе через Cloudflare R2.

---

## Отображаемое имя

Отображаемое имя (Display Name) пользователя может сохраняться вместе с определёнными сообщениями, чтобы обеспечить такие функции, как имитация пользователей.

---

## Вход в веб-панель

При входе на purgito.app через Discord запрашиваются права доступа (scopes) `identify`, `email` и `guilds`. Это позволяет показывать твоё имя пользователя, аватар и почту в рамках твоей собственной сессии, а также связывать твой аккаунт Discord с серверами, которыми ты управляешь (scope `guilds` — это то, что позволяет узнать, на каких серверах у тебя есть права администратора, чтобы показывать в панели только их). Сохраняется сессионная cookie, чтобы ты оставался авторизован во время просмотра сайта; эта cookie не используется в рекламных целях и не отслеживает тебя на других сайтах.

---

## Журнал аудита панели

Когда администратор вносит изменение настроек из веб-панели (команда `/settings`), Purgito сохраняет собственный журнал аудита для этого сервера: ID Discord и отображаемое имя того, кто внёс изменение, тип действия (например, добавление особой фразы, добавление GIF или очистка корпуса канала) и, в некоторых случаях, произвольный текстовый комментарий, который может включать контент, написанный дословно тем, кто внёс изменение.

Этот журнал виден только администраторам этого же сервера, во вкладке «История» панели, и существует для того, чтобы сообщество могло видеть, какие изменения были внесены и кем. Он хранится не более 90 дней, после чего автоматически удаляется (см. «Хранение данных»).

---

Бот **не собирает**:

- Пароли.
- Адреса электронной почты, кроме того, что предоставляет Discord при входе в веб-панель (purgito.app) — эта почта используется только для идентификации тебя в рамках твоей собственной сессии и не передаётся третьим лицам.
- Личные данные, не предоставленные официальным API Discord.

**IP-адреса:** панель управления (purgito.app) обрабатывает твой IP-адрес временно и в ограниченном объёме, исключительно для предотвращения злоупотреблений (ограничение частоты запросов). Этот IP находится только в памяти процесса в течение короткого промежутка времени (от секунд до минут), никогда не сохраняется в базе данных или в каком-либо постоянном журнале и не передаётся третьим лицам.

О платёжных данных см. раздел **«Платежи и подписки»** ниже: Purgito их не хранит, но процессор платежей (Polar.sh) собирает их при обработке покупки.

## Платежи и подписки

Когда сервер оформляет Premium через панель управления (purgito.app), оплату обрабатывает **Polar.sh**, а не Purgito.

**Purgito хранит только:**

- ID сервера (guild_id) с активным Premium.
- Дату активации.
- Текстовую пометку с указанием плана (например, «Polar — ежемесячный» или «Polar — годовой»).

Purgito **не хранит** номер карты, платёжные реквизиты, email или имя покупателя.

**Polar.sh собирает** данные, необходимые для обработки платежа (карта, email, платёжные реквизиты), согласно собственной [Политике конфиденциальности](https://polar.sh/legal/privacy). Эти отношения по данным существуют между покупателем и Polar.sh как процессором/Merchant of Record.

# 2. Использование информации

Собранная информация используется исключительно для предоставления функций бота, включая:

- Генерацию текста с помощью локальных цепей Маркова.
- Генерацию мемов и подписей (локально или через опциональную интеграцию с Groq).
- Галерею GIF.
- Автоматизации сервера.
- Настройку команд и параметров.

Данные **никогда не продаются** и не используются Purgito в рекламных целях.

# 3. Сторонние сервисы

Purgito использует внешние сервисы для определённых функций. Каждый поставщик обрабатывает только ту информацию, которая необходима для предоставления его услуги.

## Discord и хранилище

- **Discord**: для коммуникации на платформе, получения событий, аутентификации и отправки сообщений.
- **Cloudflare R2**: для постоянного хранения медиафайлов (изображений из пула мемов сервера и GIF, загруженных в галерею).

## Groq API (подписи к мемам с ИИ)

- **Что это и для чего используется**: Groq — внешний поставщик инференса моделей искусственного интеллекта (зрение и язык), используемый опционально и исключительно для анализа изображений и написания подписей в функции мемов.
- **Какие данные могут отправляться**: изображение, используемое для мема (в кодировке base64), и ограниченная выборка корпуса сервера (не более 25 коротких сообщений и 15 длинных сообщений, как образец лексики и тона).
- **Когда используется**: только при запросе или выполнении генерации мема (команда `/momo`, ответ по триггеру на изображение или запланированный мем), и только если оператор бота настроил ключ `GROQ_API_KEY`.
- **Ограниченный охват**: Groq не обрабатывает обычные разговоры в чате и не получает полный корпус ни одного сервера. Основной чат Purgito работает на 100% локально.
- **Локальный резервный вариант**: если Groq не настроен, недоступен или даёт сбой, подпись генерируется на 100% локально с помощью цепей Маркова.
- **Реклама**: данные, передаваемые в Groq в рамках этой функции, не используются Purgito в рекламных целях или для продажи данных.

## Платежи и инфраструктура

- **Polar.sh**: процессор платежей и Merchant of Record для Premium-подписок. См. его [Политику конфиденциальности](https://polar.sh/legal/privacy).
- Другие инфраструктурные сервисы, строго необходимые для работы бота.

# 4. Хранение данных

Собранные данные хранятся только до тех пор, пока они необходимы для работы бота.

История сообщений не хранится бессрочно, даже пока сервер активен: у каждого сервера есть максимальная квота сохранённых сообщений (больше на серверах с Premium). По достижении этой квоты самые старые сообщения автоматически удаляются по мере сохранения новых, без необходимости ручного вмешательства администратора.

Администраторы сервера также могут в любой момент удалить собранный контент с помощью интерактивной панели настроек (команда `/settings`), где есть кнопки для очистки изученного корпуса сообщений и удаления сохранённых GIF.

Журнал аудита панели (см. раздел 1) хранится не более 90 дней с момента каждой записи, после чего автоматически удаляется без ручного вмешательства.

Когда бот покидает сервер (например, если его исключают), данные этого сервера сохраняются в течение 30-дневного льготного периода перед полным удалением. Это сделано для того, чтобы, если бота снова пригласят в этот срок, сервер восстановил свою конфигурацию и контент без необходимости начинать с нуля. В течение этого периода, пока бота нет на сервере, доступа к панели администрирования для управления этими данными нет. На данный момент нет способа самостоятельно ускорить это удаление на уровне сервера до истечения 30 дней; если ты администратор сервера и хочешь, чтобы его данные были удалены раньше этого срока, можешь запросить это, связавшись с разработчиком (см. «Контакты» ниже).

## Удаление собственных данных (индивидуальное право на забвение)

Независимо от вышесказанного, любой пользователь может в любой момент запросить удаление собственной информации, не будучи администратором какого-либо сервера и не дожидаясь 30-дневного периода из предыдущего пункта.

Команда `/borrar_mis_datos`, доступная любому пользователю на любом сервере, где есть Purgito, безвозвратно и немедленно удаляет на **всех** серверах, где ты писал:

- Твой стиль письма, сохранённый для функции имитации (`/imitar`).
- Сообщения, которые Purgito изучил у тебя для генерации текста.

Твои оригинальные сообщения в Discord не затрагиваются: удаляется только копия, которую Purgito сохранил, чтобы учиться на твоей манере письма. Поскольку это необратимое действие, команда запрашивает явное подтверждение перед выполнением удаления.

Это удаление предназначено конкретно для данных обучения на сообщениях, описанных выше, и автоматически не покрывает другие категории, которые ты мог создать на сервере — например, GIF или изображения, добавленные тобой в пул сервера, или твои собственные записи в журнале аудита панели, если ты администратор, — поскольку они привязаны к серверу, на котором были созданы, а не только к твоему аккаунту. Если ты хочешь запросить удаление чего-либо из этого, можешь связаться с разработчиком (см. «Контакты»).

# 5. Права пользователей

Любой пользователь может удалить собственную информацию в любой момент с помощью команды `/borrar_mis_datos` (см. раздел 4), не будучи администратором какого-либо сервера.

Администраторы сервера также располагают собственными инструментами для контроля сбора данных своего сообщества (см. раздел 4), включая возможность исключать конкретных пользователей: независимо друг от друга они могут отметить, что Purgito не должен взаимодействовать с этим пользователем (не отвечать, не реагировать и не срабатывать по триггерам) и/или не должен учиться на его сообщениях (не использовать их для корпуса или для функции имитации).

Если ты считаешь, что есть информация, которую следует удалить, и она не покрывается этими инструментами самообслуживания, или у тебя есть вопросы об обработке данных, можешь связаться с разработчиком.

Когда это технически возможно, разумные запросы на удаление будут выполнены.
