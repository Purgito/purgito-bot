Wie lade ich Purgito auf meinen Server ein?
  1. Stell sicher, dass du auf dem Server, auf den du Purgito einladen willst, die Berechtigung "Server verwalten" (Manage Server) hast.
  2. Klicke oben auf dieser Seite auf "Purgito einladen".
  3. Wähle deinen Server aus und klicke auf "Weiter".
  4. Deaktiviere keine Berechtigung und klicke auf "Autorisieren".
Wie kündige oder verwalte ich mein Abonnement?

Die Zahlung wird über Polar abgewickelt, unseren Zahlungsanbieter (Merchant of Record) — die Verwaltung des Abonnements findet dort statt, nicht in diesem Panel. Beim Abschließen eines Abonnements schickt dir Polar eine Bestätigungs-E-Mail mit Zugang zu deinem Kundenportal. Von diesem Portal aus kannst du das Abonnement kündigen, jederzeit zwischen monatlichem und jährlichem Plan wechseln oder deine Belege einsehen. Falls du die E-Mail nicht findest, schau in deinem Spam- oder Werbeordner nach.

Wenn du kündigst, bleibt der Premium-Zugang bis zum Ende des bereits bezahlten Zeitraums aktiv. Nach diesem Datum verlängert sich das Abonnement nicht mehr und der Server wechselt automatisch zum kostenlosen Plan.

Bringt mir eine Spende auf Ko-fi etwas im Bot?

Nein — eine Spende auf Ko-fi ist direkte, freiwillige Unterstützung für die Entwicklung von Purgito, ohne jeglichen Vorteil im Bot oder auf dem Server. Wenn du Funktionen freischalten willst (automatische Memes, mehr Speicherkapazität, GIFs usw.), passiert das über Premium, nicht über eine Ko-fi-Spende.

Versteht Purgito jede Sprache?

Ja — Purgito übersetzt oder interpretiert die Sprache nicht, er lernt direkt das Muster des Textes, den er liest. Er funktioniert gleich gut auf Deutsch, Spanisch, Englisch oder in jeder Mischung, die auf deinem Server gesprochen wird, ohne dass du irgendetwas konfigurieren musst.

Ist Purgito Open Source?

Ja, mit einer Bedingung. Der Code von Purgito ist auf GitHub unter der MIT-Lizenz veröffentlicht — du kannst ihn ansehen, studieren, verändern und sogar eine eigene Instanz für den persönlichen Gebrauch oder deinen Server betreiben, alles kostenlos und ohne um Erlaubnis zu fragen. Die einzige Einschränkung, hinzugefügt über die sogenannte "Commons Clause", ist, dass du die Software nicht verkaufen oder für einen Dienst bezahlen lassen darfst, dessen Wert größtenteils von ihr abhängt — zum Beispiel, diesen Code zu nehmen, um deinen eigenen kostenpflichtigen Bot zu betreiben oder Dritten das Hosting in Rechnung zu stellen. Abgesehen von dieser konkreten Einschränkung ist es echter Open Source.
