Reference

Environment variables

Three files, with different rules: .env holds secrets and is never versioned; urls.env and limits.env are in the repo. All three are loaded when src/config.py is imported. None of the actual values appear here — just the names and what each is for.

.env — secrets and deployment-specific configuration

VariableWhat it's for
DISCORD_TOKENThe bot's token.
ENABLE_MESSAGE_CONTENTEnables the message content intent.
GUILD_IDDevelopment server for syncing slash commands instantly.
BOT_TRIGGER_NAMEWord that triggers meme generation via text.
BOT_OWNER_IDDiscord ID of the bot's owner.
GROQ_API_KEYGroq key for AI meme captions (falls back to Markov if missing).
REFEED_MAX_MESSAGES / REFEED_ALL_MAX_MESSAGESCap on messages read by /refeed and /refeed_all.
MARKOV_TRAINING_MESSAGES / USER_MARKOV_TRAINING_MESSAGESSample size for training the per-server / per-user model.
AUTO_GENERATE_PROBABILITYSpontaneous reply probability (fallback if the server hasn't set its own).
GUILD_DATA_RETENTION_DAYSGrace period before purging the data of a server that kicked the bot.
AUDIT_LOG_RETENTION_DAYSMaximum age of the audit log.
R2_ACCESS_KEY_ID, R2_SECRET_ACCESS_KEY, R2_ENDPOINT_URL, R2_BUCKET_NAME, R2_PUBLIC_URLCloudflare R2 credentials — all five together enable R2.
WEB_PORTLocal port for the API.
DISCORD_CLIENT_ID / DISCORD_CLIENT_SECRETCredentials for the dashboard's OAuth2 app.
SESSION_SECRETEncryption key for the session cookie.
DASHBOARD_ENABLEDForces the dashboard on/off.
POLAR_ACCESS_TOKEN, POLAR_WEBHOOK_SECRET, POLAR_SERVER, POLAR_PRODUCT_ID_MONTHLY, POLAR_PRODUCT_ID_ANNUALPolar payment integration.
ANNOUNCEMENTS_TIMEZONETime zone for announcements scheduled at a fixed time.

urls.env — public URLs, versioned in git

VariableWhat it's for
PANEL_URLPublic URL of the dashboard.
DASHBOARD_BASE_URLHost used to build the OAuth2 redirect_uri.
LANDING_URLDestination after logging in from the landing page.
LANDING_ORIGINSAllowed origins for authenticated cross-site requests.
SESSION_COOKIE_DOMAINDomain of the session cookie.
SUPPORT_URLLink to the support server.
DOCS_URLPublic URL of this documentation.
REPO_URLLink to the repository.

limits.env — per-server quotas, versioned in git

Almost all of them come in pairs for the free plan and Premium.

VariableWhat it's for
MAX_CORPUS_MESSAGES_PER_GUILD_FREE / _PREMIUMCorpus cap per channel.
MAX_CORPUS_MESSAGES_PER_GUILD_TOTAL_FREE / _PREMIUMCorpus cap for the whole server.
MAX_USER_CORPUS_MESSAGES_PER_GUILD_FREE / _PREMIUMCorpus cap per author.
MAX_GIFS_PER_GUILD_FREE / _PREMIUMCap on GIFs saved per server.
MAX_GIF_DOWNLOAD_BYTESMaximum accepted GIF size.
GIF_LOSSY_LEVELCompression level when uploading GIFs.
MAX_IMAGES_PER_GUILD_FREE / _PREMIUMCap on meme images per server.
MAX_ANNOUNCEMENTS_PER_GUILD_FREE / _PREMIUMCap on scheduled announcements.
MAX_EMBED_TEMPLATES_PER_GUILD_FREE / _PREMIUMCap on saved embed templates.
MAX_EMBED_IMAGE_UPLOAD_BYTESMaximum size of an image uploaded from the embed editor.
MAX_SHARE_LINKS_PER_GUILD_DAYDaily cap on generated shareable embed links.
MAX_LAYOUT_FILE_UPLOAD_BYTESMaximum size of a file uploaded in a "File" block in the editor.
