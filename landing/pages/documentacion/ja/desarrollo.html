開発

ローカル環境の構築、自動テストスイートの実行、そしてPurgitoのコードへの貢献に関する技術ガイドです。

リポジトリの構成

  • src/bot.py — Discordボットのエントリーポイント、インテントの設定、cogの読み込み順序。
  • src/config.py — 環境変数(.env、urls.env、limits.env)の読み込みと検証を一元化するモジュール。
  • src/db.py — SQLite(aiosqlite)上の非同期永続化層、自動マイグレーション、トランザクション。
  • src/webapi.py — すべてのJSON REST エンドポイント、OAuth2認証、Webhookを備えたaiohttp.webサーバー。
  • src/markov_engine.py — 1次・2次のマルコフ連鎖による確率的エンジンの実装。
  • src/r2.py — Cloudflare R2向けのS3互換クライアント。SHA-256ハッシュによるメディアの重複排除と知覚ハッシュ。
  • src/tasks.py — 定期的なスケジュールタスク(サーバーの遅延削除、監査ログの失効、各種配信)。
  • src/cogs/ — 機能ごとに整理されたDiscordのcog(chat、gifs、memes、youtube、rss、premium、anuncios、settings、layout_buttons)。
  • landing/ — 静的フロントエンド:HTMLページ(landing/pages/)、CSSスタイル(landing/style.css、landing/dash.css)、モジュール化されたJavaScript(landing/js/)。
  • landing/build_docs.py — HTMLページのビルドスクリプト。共通レイアウトの差し込みと、キャッシュバスティング用ハッシュの計算を行います。
  • tests/ — pytestによる自動テストスイートと、Node.jsによるフロントエンドのテスト。

ローカル開発環境

必要条件:Python 3.11以上(推奨は3.12)、フロントエンドのテスト用にNode.js 18+。

1. 環境ファイルの設定

Purgitoは、それぞれ役割の異なる3つの独立した設定ファイルを使用します:

  • .env:開発用のシークレットとトークン(Discordボットのトークン、OAuth2の認証情報、セッションの鍵、Webhook)。Gitではバージョン管理されません。.env.exampleからコピーしてください。
  • urls.env:アプリケーションの公開URLとエンドポイント。Gitでバージョン管理されます。
  • limits.env:無料プラン・Premiumプランごとの、サーバー単位のクォータと保存上限。Gitでバージョン管理されます。

2. 依存関係のインストール

# 仮想環境の作成と有効化
python3 -m venv .venv
source .venv/bin/activate

# ボットとテストツールの依存関係をインストール
pip install -r requirements.txt pytest ruff

テストとLintの実行

Pythonの単体テスト(pytest)

# ボットとAPIの自動テストをすべて実行
.venv/bin/python -m pytest tests -q

# 特定のテストファイルのみ実行
.venv/bin/python -m pytest tests/test_dashboard_routes.py -v

フロントエンドのテスト(Node.js)

# ダッシュボードSPAの統合テスト
node landing/test_dash.mjs

# 多言語対応(ES / EN)の整合性テスト
node landing/test_lang.mjs

Ruffによるフォーマットと静的解析

# コードのスタイルとルールを検証
ruff check .

# コードを自動フォーマット
ruff format .

ドキュメントとウェブページの生成

landing/pages/、landing/js/、landing/style.css、landing/dash.cssのいずれかを変更した際は、キャッシュバスティング用ハッシュを更新し、言語間の整合性を確認するためにページを再生成する必要があります:

# landing/es/ と landing/en/ の静的ページを再生成
.venv/bin/python landing/build_docs.py

# 生成されたファイルがリポジトリと完全に一致するか確認(CIで使用)
.venv/bin/python landing/build_docs.py --check
