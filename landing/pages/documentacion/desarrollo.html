Development

Project Structure

  • src/cogs/ — comandos y features del bot (chat, gifs, memes, youtube, premium, anuncios, layout_buttons, settings, general).
  • src/webapi.py — la API JSON completa.
  • landing/ — sitio estático: index.html, style.css, script.js.
  • landing/pages/ — cuerpos de página escritos a mano; build_docs.py les agrega navbar/footer/head.
  • landing/js/ + landing/dash.css — el dashboard, módulos ES nativos sin bundler.
  • data/bot.db — la base SQLite.

Local Setup

El bot es Python 3.11+; CI corre en 3.12. Tres archivos de entorno con reglas distintas: .env (secretos, no versionado — nombres esperados en .env.example), urls.env (URLs públicas, versionado) y limits.env (cuotas por servidor, versionado). Los tres se cargan al importar src/config.py.

Testing

# pytest no está en requirements.txt — usar el venv del proyecto.
.venv/bin/python -m pytest tests -q

# Lint y formato, corren en CI.
ruff check .
ruff format --check .

# Regenera las páginas de landing/es/ — correr después de tocar
# docs/*.md, landing/pages/*, cualquier .css o .js.
.venv/bin/python landing/build_docs.py
.venv/bin/python landing/build_docs.py --check

No hay pytest.ini: los tests se descubren solos desde tests/.
