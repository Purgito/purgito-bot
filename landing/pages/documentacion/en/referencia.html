Reference

Technical reference documentation for all environment variables used by Purgito, organized across three distinct configuration files based on sensitivity and lifecycle.

Configuration Files

The src/config.py module automatically loads all three files when initializing the application. Secrets reside exclusively in .env (ignored by Git), while public URLs and limit constants are versioned in urls.env and limits.env.

.env — Secrets and Deployment Settings

VariableTypeDescription and purpose
DISCORD_TOKENstringSecret authentication token for the bot on Discord's Gateway and REST API.
ENABLE_MESSAGE_CONTENTbooleanEnables the privileged Message Content intent (message_content). Required for corpus ingestion.
GUILD_IDintegerDevelopment guild ID used for instant slash command synchronization during local debugging.
BOT_TRIGGER_NAMEstringTrigger keyword or reserved word that invokes automatic meme rendering and contextual replies.
BOT_OWNER_IDintegerDiscord user ID of the bot operator with access to administrative commands.
GROQ_API_KEYstringGroq API key for AI vision meme captioning. Falls back to the Markov engine if undefined.
REFEED_MAX_MESSAGESintegerMaximum messages read when re-indexing an individual channel via /refeed.
REFEED_ALL_MAX_MESSAGESintegerMaximum cumulative messages read when re-indexing all guild channels via /refeed_all.
MARKOV_TRAINING_MESSAGESintegerRandom sample size extracted from the corpus table to compile the server's Markov model.
USER_MARKOV_TRAINING_MESSAGESintegerSample size extracted to train per-user Markov models (imitation commands).
AUTO_GENERATE_PROBABILITYfloatBase probability (0.0 to 1.0) of spontaneous reply when a server has not set a custom override.
GUILD_DATA_RETENTION_DAYSintegerGrace period in days before permanently purging data from servers that removed the bot (default: 30).
AUDIT_LOG_RETENTION_DAYSintegerMaximum age in days before pruning records from the audit_log table (default: 90).
R2_ACCESS_KEY_ID, R2_SECRET_ACCESS_KEYstringS3 access credentials for the Cloudflare R2 object storage bucket.
R2_ENDPOINT_URL, R2_BUCKET_NAME, R2_PUBLIC_URLstringCloudflare R2 endpoint URL, bucket identifier, and public CDN domain serving stored media.
WEB_PORTintegerLocal TCP port where the internal aiohttp HTTP server listens (default: 8080).
DISCORD_CLIENT_ID, DISCORD_CLIENT_SECRETstringDiscord OAuth2 application credentials for authenticating web dashboard users.
SESSION_SECRETstringBase64 secret key used to symmetrically encrypt session cookies with the Fernet algorithm.
DASHBOARD_ENABLEDbooleanMaster switch enabling or disabling web dashboard routes.
POLAR_ACCESS_TOKEN, POLAR_WEBHOOK_SECRETstringAPI token and HMAC secret used to verify incoming Polar billing webhooks.
POLAR_PRODUCT_ID_MONTHLY, POLAR_PRODUCT_ID_ANNUALstringPolar product IDs for monthly and annual premium subscriptions.
ANNOUNCEMENTS_TIMEZONEstringDefault IANA timezone used to calculate fixed-time announcement schedules.

limits.env — Quotas and Capacity Tiers

VariablePurpose
MAX_CORPUS_MESSAGES_PER_GUILD_FREE / _PREMIUMMaximum messages retained per channel (15,000 / 50,000).
MAX_CORPUS_MESSAGES_PER_GUILD_TOTAL_FREE / _PREMIUMMaximum total corpus capacity across the entire guild (150,000 / 500,000).
MAX_USER_CORPUS_MESSAGES_PER_GUILD_FREE / _PREMIUMMaximum messages stored per author for individual mimicry models (5,000 / 20,000).
MAX_GIFS_PER_GUILD_FREE / _PREMIUMMaximum GIFs stored in the guild catalog (1,500 / 4,000).
MAX_GIF_DOWNLOAD_BYTESMaximum byte size accepted when downloading remote GIFs (default: 10 MB).
GIF_LOSSY_LEVELLossy compression level applied when optimizing GIFs for R2 storage.
MAX_IMAGES_PER_GUILD_FREE / _PREMIUMMaximum meme template images stored in the server image bank (50 / 200).
MAX_ANNOUNCEMENTS_PER_GUILD_FREE / _PREMIUMMaximum scheduled automated announcements per server (3 / 10).
MAX_EMBED_TEMPLATES_PER_GUILD_FREE / _PREMIUMMaximum saved message designer templates (10 / 50).
MAX_EMBED_IMAGE_UPLOAD_BYTESMaximum byte size for images uploaded via the embed designer (default: 8 MB).
MAX_SHARE_LINKS_PER_GUILD_DAYDaily limit on shareable template links generated by a guild.
MAX_LAYOUT_FILE_UPLOAD_BYTESMaximum byte size for files uploaded in Layout V2 "File" blocks.
