Development

Technical guide for configuring local development environments, running automated test suites, and contributing to Purgito.

Repository Structure

  • src/bot.py — Discord bot entrypoint, Gateway intents configuration, and cog initialization order.
  • src/config.py — Centralized module loading and validating environment variables (.env, urls.env, limits.env).
  • src/db.py — Asynchronous SQLite persistence layer (aiosqlite), schema migrations, and write locking.
  • src/webapi.py — aiohttp.web server containing all JSON REST routes, OAuth2 authentication, and webhook handlers.
  • src/markov_engine.py — Custom probabilistic first- and second-order Markov chain implementation.
  • src/r2.py — S3-compatible client for Cloudflare R2, media deduplication via SHA-256 and perceptual hashing.
  • src/tasks.py — Scheduled coroutines (grace period guild purges, audit log cleanup, and recurring dispatches).
  • src/cogs/ — Discord cogs organized by feature (chat, gifs, memes, youtube, premium, anuncios, settings, layout_buttons).
  • landing/ — Static frontend: source HTML bodies (landing/pages/), CSS stylesheets (landing/style.css, landing/dash.css), and modular JavaScript (landing/js/).
  • landing/build_docs.py — Page builder script compiling static pages, injecting shared layout shells, and generating cache-busting hashes.
  • tests/ — Automated test suite with pytest and frontend tests with Node.js.

Local Development Setup

Prerequisites: Python 3.11 or higher (3.12 recommended) and Node.js 18+ for frontend tests.

1. Environment Files Configuration

Purgito uses three distinct environment files tailored to specific lifecycle requirements:

  • .env: Secrets and local tokens (Discord bot token, OAuth2 client credentials, session encryption keys, webhook secrets). Not versioned in Git. Copy from .env.example.
  • urls.env: Public URLs and operational endpoints. Versioned in Git.
  • limits.env: Storage quotas and limit tiers for Free and Premium servers. Versioned in Git.

2. Installing Dependencies

# Create and activate virtual environment
python3 -m venv .venv
source .venv/bin/activate

# Install bot dependencies and testing tools
pip install -r requirements.txt pytest ruff

Running Tests and Linting

Python Unit Tests (pytest)

# Run all automated tests for the bot and web API
.venv/bin/python -m pytest tests -q

# Run a specific test module
.venv/bin/python -m pytest tests/test_dashboard_routes.py -v

Frontend Test Suites (Node.js)

# Run SPA dashboard integration tests
node landing/test_dash.mjs

# Run internationalization parity tests (ES / EN coverage)
node landing/test_lang.mjs

Formatting and Static Analysis (Ruff)

# Check code style and lint rules
ruff check .

# Apply automatic formatting fixes
ruff format .

Building Documentation and HTML Pages

Whenever modifying files in landing/pages/, landing/js/, landing/style.css, or landing/dash.css, regenerate the compiled pages to refresh cache-busting hashes and ensure bilingual parity:

# Regenerate static pages in landing/es/ and landing/en/
.venv/bin/python landing/build_docs.py

# Verify generated files match the repository exactly (used in CI)
.venv/bin/python landing/build_docs.py --check
