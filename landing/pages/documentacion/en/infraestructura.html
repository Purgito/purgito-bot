Infrastructure

Purgito operates on an optimized single-node Linux host: an Nginx reverse proxy at the edge, a unified asynchronous Python process managed by systemd, and Cloudflare as the perimeter CDN and security layer.

Runtime Environment

The Discord bot and its web API run co-located in a single Python 3.11+ process within the same asynchronous event loop (asyncio):

  • systemd Service Management: The bot-purg.service unit file supervises process lifecycle, handling automatic crash recovery and structured logging to journald.
  • Network Isolation: The HTTP API (aiohttp) binds strictly to 127.0.0.1:WEB_PORT (default: port 8080/8081). No Python socket is exposed directly to the public internet.

Nginx Topology

Nginx serves as the sole local entry point, cleanly bifurcating static asset delivery from dynamic application routing:

Incoming Request (HTTPS)
           │
           ▼
     ┌───────────┐
     │   Nginx   │
     └─────┬─────┘
           │
     ┌─────┴────────────────────────────────┐
     │                                      │
     ▼ Dynamic Routes                       ▼ Static Routes
/api/*, /auth/*, /webhooks/*, /health       /es/*, /en/*, /assets/*, /style.css
     │                                      │
     ▼ proxy_pass                           ▼ try_files
┌─────────────────────────┐           ┌─────────────────────────┐
│  Python 127.0.0.1:8080  │           │     Direct from disk    │
│   aiohttp REST API      │           │     (Zero Python CPU)   │
└─────────────────────────┘           └─────────────────────────┘
  • High-Performance Static Delivery: All HTML pages (landing, guide, documentation, dashboard), CSS styles, JS scripts, and public images are served directly from the filesystem without consuming application runtime resources.
  • Dashboard Dynamic Segment Routing: Nginx routes any guild-scoped URL (e.g. /en/dashboard/{id}/*) to the appropriate static dashboard index file, allowing the client-side SPA router to take over.
  • Security and Caching Headers: Nginx applies strict HTTP security headers (CSP, X-Content-Type-Options, Referrer-Policy) and attaches Cache-Control: public, max-age=31536000, immutable headers to cache-busted asset requests (?v=...).

CDN and Perimeter Security (Cloudflare)

Cloudflare sits in front of the origin server as a TLS proxy and content distribution network:

  • TLS 1.3 Termination: Manages SSL/TLS certificates and client-side encryption handshakes.
  • Edge Caching: Caches static assets globally across edge data centers, absorbing landing page traffic and eliminating origin server load.
  • DDoS Mitigation & WAF: Filters malicious traffic and volumetric denial-of-service attacks before packets reach the host Nginx port.

Continuous Deployment Without Build Steps

Purgito's architecture eliminates server-side build steps and compilation overhead:

  1. Source code, modular scripts, and pregenerated documentation pages from landing/build_docs.py are versioned directly in Git.
  2. Deployments consist of synchronizing repository state via git pull.
  3. Documentation integrity is validated via python3 landing/build_docs.py --check.
  4. The service is reloaded with systemctl restart bot-purg.service, completing the zero-downtime update in seconds.
