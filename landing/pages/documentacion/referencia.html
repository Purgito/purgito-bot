Referencia

Documentación técnica de referencia de todas las variables de entorno utilizadas por Purgito, distribuidas en tres archivos según su ciclo de vida y privacidad.

Archivos de Configuración

El módulo src/config.py carga automáticamente los tres archivos al importar la aplicación. Los secretos residen exclusivamente en .env (ignorado por Git), mientras que las constantes de URLs y cuotas están versionadas en urls.env y limits.env.

.env — Secretos y Configuración de Despliegue

VariableTipoDescripción y propósito
DISCORD_TOKENstringToken secreto de autenticación del bot en el Gateway y API REST de Discord.
ENABLE_MESSAGE_CONTENTbooleanHabilita el intent privilegiado de contenido de mensajes (message_content). Requerido para capturar el corpus.
GUILD_IDintegerID de servidor de desarrollo para sincronización instantánea de comandos slash durante pruebas locales.
BOT_TRIGGER_NAMEstringNombre clave o palabra reservada que dispara la generación de memes y respuestas contextuales por texto.
BOT_OWNER_IDintegerID de usuario de Discord del propietario del bot con acceso a comandos de mantenimiento.
GROQ_API_KEYstringClave API de Groq para generación de captions de memes mediante modelos de visión por IA. Si no se define, se utiliza el motor de Markov.
REFEED_MAX_MESSAGESintegerLímite máximo de mensajes leídos al reentrenar un canal individual con /refeed.
REFEED_ALL_MAX_MESSAGESintegerLímite máximo de mensajes acumulados al reentrenar todos los canales del servidor con /refeed_all.
MARKOV_TRAINING_MESSAGESintegerTamaño de la muestra aleatoria de mensajes extraída de la tabla corpus para compilar el modelo de Markov del servidor.
USER_MARKOV_TRAINING_MESSAGESintegerTamaño de la muestra de mensajes para entrenar modelos específicos por usuario (comandos de imitación).
AUTO_GENERATE_PROBABILITYfloatProbabilidad base (0.0 a 1.0) de respuesta espontánea cuando el servidor no ha establecido un valor personalizado.
GUILD_DATA_RETENTION_DAYSintegerDías de período de gracia antes de purgar definitivamente los datos de un servidor que expulsó al bot (por defecto: 30).
AUDIT_LOG_RETENTION_DAYSintegerAntigüedad máxima en días para conservar registros en la tabla audit_log (por defecto: 90).
R2_ACCESS_KEY_ID, R2_SECRET_ACCESS_KEYstringCredenciales de acceso S3 para el bucket de Cloudflare R2.
R2_ENDPOINT_URL, R2_BUCKET_NAME, R2_PUBLIC_URLstringEndpoint de Cloudflare R2, nombre del bucket y dominio público CDN para servir los medios alojados.
WEB_PORTintegerPuerto local TCP donde escucha el servidor HTTP aiohttp (por defecto: 8080).
DISCORD_CLIENT_ID, DISCORD_CLIENT_SECRETstringCredenciales de la aplicación OAuth2 de Discord para autenticar usuarios en el dashboard.
SESSION_SECRETstringClave secreta base64 utilizada para cifrar simétricamente las cookies de sesión con el algoritmo Fernet.
DASHBOARD_ENABLEDbooleanInterruptor maestro para habilitar o deshabilitar las rutas del dashboard web.
POLAR_ACCESS_TOKEN, POLAR_WEBHOOK_SECRETstringToken de API y secreto HMAC para validar la firma de los webhooks de facturación de Polar.
POLAR_PRODUCT_ID_MONTHLY, POLAR_PRODUCT_ID_ANNUALstringIdentificadores de producto en Polar para suscripciones mensual y anual.
ANNOUNCEMENTS_TIMEZONEstringZona horaria IANA por defecto utilizada para calcular los envíos de anuncios programados a hora fija.

urls.env — URLs Públicas y Enlaces del Ecosistema

VariableDescripción y propósito
PANEL_URLURL pública base del dashboard y panel de administración (ej. https://purgito.app).
DASHBOARD_BASE_URLHost público utilizado para construir la URL de redirección (redirect_uri) del flujo OAuth2.
LANDING_URLURL de destino tras completar el inicio de sesión desde la página principal.
LANDING_ORIGINSLista de orígenes permitidos en cabeceras CORS para peticiones autenticadas entre dominios.
SESSION_COOKIE_DOMAINDominio de alcance configurado en la cabecera Set-Cookie para la cookie de sesión.
SUPPORT_URLEnlace de invitación al servidor oficial de Discord de soporte y comunidad de Purgito.
DOCS_URLURL pública de la documentación técnica y guías.
REPO_URLEnlace al repositorio oficial de código fuente en GitHub.

limits.env — Cuotas y Capacidad por Servidor

VariablePropósito
MAX_CORPUS_MESSAGES_PER_GUILD_FREE / _PREMIUMLímite máximo de mensajes en memoria conservados por canal (15.000 / 50.000).
MAX_CORPUS_MESSAGES_PER_GUILD_TOTAL_FREE / _PREMIUMCapacidad total máxima de mensajes del corpus por servidor (150.000 / 500.000).
MAX_USER_CORPUS_MESSAGES_PER_GUILD_FREE / _PREMIUMLímite máximo de mensajes almacenados por autor para modelos individuales (5.000 / 20.000).
MAX_GIFS_PER_GUILD_FREE / _PREMIUMTope de GIFs en el catálogo del servidor (1.500 / 4.000).
MAX_GIF_DOWNLOAD_BYTESTamaño máximo en bytes permitido al descargar un GIF remoto (por defecto: 10 MB).
GIF_LOSSY_LEVELNivel de compresión con pérdida aplicado al optimizar GIFs para almacenamiento en R2.
MAX_IMAGES_PER_GUILD_FREE / _PREMIUMTope de imágenes guardadas en el banco de memes del servidor (50 / 200).
MAX_ANNOUNCEMENTS_PER_GUILD_FREE / _PREMIUMTope de anuncios automatizados programables en el servidor (3 / 10).
MAX_EMBED_TEMPLATES_PER_GUILD_FREE / _PREMIUMTope de plantillas guardadas en el diseñador de mensajes (10 / 50).
MAX_EMBED_IMAGE_UPLOAD_BYTESTamaño máximo en bytes de imágenes subidas al editor de embeds (por defecto: 8 MB).
MAX_SHARE_LINKS_PER_GUILD_DAYLímite diario de enlaces compartibles de plantillas que un servidor puede generar.
MAX_LAYOUT_FILE_UPLOAD_BYTESTamaño máximo de archivos adjuntos subidos en un bloque "Archivo" de Layout V2.
